# /hint

1. `python3 engine/dmc.py hint`: mở gợi ý kế tiếp (bậc 1 → 3, từ hướng suy nghĩ đến gợi ý cụ thể).
2. In gợi ý kèm "bậc k/3". Có thể diễn đạt lại cho gọn nhưng không thêm thông tin, không bao giờ lộ đáp án.
   Hết gợi ý: nói đã mở hết, khuyến khích viết câu trả lời rồi `/submit`.
3. `git add state && git commit -m "Hint {k} for {date}" && git push -u origin main`
